# The Seventh

This is a horror Roblox game where seven players enter a creepy mansion. One player is randomly chosen to become a monster and must eliminate the other six survivors. The survivors must complete tasks around the mansion to open the escape door.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new place or open an existing one.
4. Place the `GameManager.server.lua` script in the `ServerScriptService` folder.
5. Place the `PlayerController.client.lua`, `MonsterAbilities.client.lua`, `SurvivorTasks.client.lua`, and `EscapeDoor.client.lua` scripts in the `StarterPlayerScripts` folder.

## Use

1. Start the game by triggering the `StartGame` remote event.
2. The game will randomly assign one player as the monster and the rest as survivors.
3. Survivors must complete tasks around the mansion to open the escape door.
4. The monster must eliminate all survivors before they can escape.
5. If all tasks are completed, the escape door will open, and survivors can escape.
